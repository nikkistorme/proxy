PROXY · UI PLACEMENT GUIDE · DRAFT 1 · OCT 29 2026

Every feature gets an address before it gets a button.

This guide sets out the places features live in, the rules for choosing between them, and where every current and planned feature goes. Issues cite the rule IDs (UI-n) the same way they cite requirement IDs. Then new work fits the plan, and the header doesn't grow each time.

Grounded in the local codebase: SessionScreen, SessionMenu, TableTools, design/tokens.css and HANDOFF.md. The diagrams use Proxy's tokens and fonts but stay low-fidelity. New dialogs follow MoveDialog, side sheets follow PileViewer, menus follow ActionMenu.

04 · OBJECT ACTIONS

Where card and pile actions show up: three options

Whichever option you pick, the actions come from one action registry (UI-2). Each action has an id, a label, a shortcut, the objects it applies to, and a can() check. Menus, the palette, #53's settings and the announcements all read from it. That makes the choice below about presentation only. It can change later without a rework.

05 · SEAT DOCK

One strip per seat, not a seat bar plus a hand tray

The seat switcher, counters and hand are one component, so switching seats (S / Shift+S) changes everything in one place. Anything that belongs to a seat goes here later, such as hidden info or a seat's private piles.

06 · HOME, LIBRARY, ACCOUNT

The workspace, organised by game

Home lists games and their sessions. The Library holds reusable things. Within a game, the "In this game" links open the Library filtered to that game, so a game is a filter, not a second copy of the Library.

### Placement (UI-1 to UI-8) - Acts on: card / pile / stack / selection / seat / session / view / library item / person - Address: place letter + name (see docs/ui-placement.md) - Registry entry: action id, label, default shortcut (or none), applies to, can() capability - Header impact: none (if not none, say which slot and why — UI-3) - Shown when: always / condition (UI-4) - Phone: how it shows (sheet, menu, ⋯) - Testers (#106): visible / hidden
